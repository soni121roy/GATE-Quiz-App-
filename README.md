# GATE CS PYQ Quiz App

A simple and responsive quiz app for GATE Computer Science aspirants to practice Previous Year Questions.

**Live Demo:** https://soni121roy.github.io/GATE-Quiz-App-/

### Features
- Subject-wise Quiz: OS, DBMS, CN
- 30s Timer per question
- Instant Scoring
- Responsive & Dark UI
- No login needed

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
